- BREAKING: `kiroku serve` no longer accepts an address with `?key=<key>` (made by versions before v0.38.2), even when the key is right: it shows the page that says to run `kiroku open`. Such an address stays in the browser's history with the key in it, and the key itself still works, so if you ever opened one, change the key: stop `kiroku serve`, delete `serve-key` in kiroku's settings folder, start it again and run `kiroku open`. Bookmarks of the plain address and browsers already opened with `kiroku open` keep working
- BREAKING: `kiroku serve --ai` is gone. "Analyze with AI" has been on by default since v0.36.1 and `--ai` only printed a notice (and `--ai=false` turned runs off); `--ai` and `--ai=false` now stop with a message that says to use `--no-ai` to turn it off
