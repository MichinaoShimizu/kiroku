- `kiroku serve` reads Git faster when it reloads after your history changes: it remembers which repository each working directory belongs to instead of running `git rev-parse` for every one on each reload, and it checks repositories in parallel (up to 8 at a time). Reloading 20 unchanged repositories with 100 working directories took about 46 ms instead of 355 ms in the benchmark, and the first read about 126 ms instead of 429 ms
