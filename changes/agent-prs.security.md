- A pull request link whose URL only contains `github.com` in its path (such as `https://evil.example/github.com/owner/repo/pull/1`) is no longer shown under a GitHub pull request name like "repo#1"; the short name is used only for `https://github.com/` URLs, so the name always matches where the link goes. URLs with invisible or direction-changing characters (such as U+202E) are not used as pull request links
