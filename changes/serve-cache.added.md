- `kiroku serve` starts much faster the second time: it saves the Claude Code and Codex history it read to `serve-cache` in kiroku's cache folder (`~/.cache/kiroku` on Linux, `~/Library/Caches/kiroku` on macOS, `%LocalAppData%\kiroku-cache` on Windows, or `$KIROKU_CACHE_DIR`) and the next start reads only conversations that changed. With a year of synthetic history it reads in 0.18 s instead of 0.75 s; real history, whose files are mostly tool output kiroku doesn't keep, gains more. `--no-cache` turns this off and deletes the saved file
