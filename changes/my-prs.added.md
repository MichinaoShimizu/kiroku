- `kiroku serve --prs` (off by default) adds a "Pull requests" page next to Calendar and Summary: tables of the open pull requests you opened, that request your review or that mention you, each with its repository, checks, review decision and merge state (conflicts, draft) in columns of their own, a link to the session that created it when your history has one, and "Copy prompt" for its next step (fix failing checks, address the review, resolve conflicts, check that it is ready to merge, review it, or reply to a mention). It needs the GitHub CLI (`gh`), logged in. kiroku asks GitHub only when you open or refresh the list, with one fixed read-only question that contains nothing from your history; the prompt contains only the pull request's address and status, never its title or description
