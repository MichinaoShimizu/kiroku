- `kiroku serve --prs` (off by default) adds a "Pull requests" page next to Calendar and Summary: tables of the open pull requests you opened, that request your review or that mention you, each with its repository and its status drawn as the steps to merging (draft, checks, review, merge) with where it is stopped and for how long; above them, a chart of where your own pull requests are stopped, the sessions related to it (the ones whose history records creating it, or merging or reviewing it by its address), and one copy button per instruction, named after it (fix the failing checks, address the review, resolve the conflicts, check that it is ready to merge, see what it is waiting for, review it, or reply to a mention). It needs the GitHub CLI (`gh`), logged in. kiroku asks GitHub only when you open or refresh the list, with one fixed read-only question that contains nothing from your history; the prompt contains only the pull request's address and status, never its title or description
